# Inside the Realtek RTL8188CUS WiFi firmware

A reverse-engineering documentation project for the 8051 firmware of the
RTL8188CUS / RTL8192CU WiFi chips — the silicon inside the classic Edimax
EW-7811Un USB stick that a generation of Raspberry Pis went online with.

- Start here: [Findings](../analysis/findings.md) · [Symbol database](../analysis/annotations.tsv)
- Tools (build your own disassembly from your lawfully obtained linux-firmware
  copy): [tools/](../tools/) — MIT licensed.

  [README](../README.md).
